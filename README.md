## Sobre o projeto

- Com este programa, é possível criar uma tabela de frequências facilmente apenas enviando os dados;
- Eu criei este programa para tanto melhorar a base das minhas habilidades de programação quanto para o meu estudo de Probabilidade e Estatística;
- Atualmente o programa pode receber dados e criar uma tabela contendo [Frequência absoluta | Frequência acumulatica | Frequência relativa].
