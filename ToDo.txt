    Como irá funcionar?
        Ideias:
            Básico:
                - Haverá opções para navegar no programa, que podem ser escolhidas por meio de um input.
                    * Quais são as opções essenciais?
                        "Entrar em uma tabela de dados" -> Caso exista uma já criada.
                        "Criar nova tabela de dados"
                        "Remover tabela de dados"
                        "Sair"
                    SAINDO DO BÁSICO
                    * As opções podem ser mais constituídas, podendo ter condições para aparecerem ou não;
                    * Podem haver uma ação atrelada à opção, ao invés de ser hardcoded por meio do input() (ex: if input == 1, elif input == 2...) -> FEITO
                    * Criar uma classe para as opções. -> FEITO
            Avançado:
                - Guardar os dados em um .txt para que o programa lembre do último uso feito por meio de "saves".
                    * O programa fará uma "save" para cada tipo de dado;
                    * Se o usuário adicionar um dado com o nome de "Pessoas", terá um save com os dados do tipo "Pessoas" que guardará os dados que a pessoa adicionou;
                    * O programa pode mostrar alguns dados gerais do uso de cada save como:
                        "Save 1: Data_Type: Pessoas | Dados totais: 20

                    * A pessoa pode entrar num save e então modificar as informações como: Nome, adicionar dado, remover dado;
